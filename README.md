# SpaceX Falcon 9 Landing Prediction

## Project Overview
This project predicts whether the Falcon 9 first stage will land successfully using data from the SpaceX API and web scraping.

## Repository Structure
- `/notebooks` - notebooks for each lab
- `/images` - Flowcharts and visualizations
- `/data` - CSV datasets
